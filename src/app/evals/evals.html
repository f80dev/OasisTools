Import batch d'évaluations depuis un fichier Excel OASIS

description Format du fichier Excel attendu Le fichier doit contenir une feuille nommée OASIS avec les colonnes suivantes
En-tête de colonne Préfixe reconnu Obligatoire Description
Code discipline disci... Oui Code de la discipline / cours évalué
Code étudiant etudi... Oui Code de l'étudiant à évaluer
Statut statu... Oui Statut de l'évaluation (transmis tel quel à l'API)
Mention menti... Non Mention associée à l'évaluation
Commentaire comme... Non Commentaire libre attaché à l'évaluation

info Seuls les 5 premiers caractères des en-têtes sont utilisés pour identifier les colonnes (insensible à la casse). Une ligne est traitée uniquement si les colonnes discipline et étudiant sont renseignées.
